# Изменения

## 2.2.0
- Встроенный ключ шифрования удалён: ключ задаётся при установке (`install.sh`), командой
  `jpgs set-key` или в окне программы при первом запуске. Хранится в `~/.config/jpgs/key` (права 600).
- Перетаскивание изображений/`.jpgs` в окно с открытым `.jpgs` дописывает кадры в этот файл
  (без создания копий).
- Контекстное меню (правый клик) для изображения, архива и видео: сдвиг/удаление/вынос кадра,
  разделение архива, скорость видео, сохранение кадра, переименование, «Показать в папке», свойства.

## 2.1.1
- Видео не запускалось в русской локали (`mpv_create()` требует `LC_NUMERIC=C`).

## 2.1.0
- Видео `.vids`: воспроизведение через libmpv (FFmpeg), миниатюры через PyAV, потоковое шифрование.

## 2.0.1
- Миниатюры `.jpgs` в Dolphin / Nautilus / Nemo / Thunar.

## 2.0.0
- Переписано с Java/Swing на Python + GTK 4 / libadwaita: в 3–4 раза меньше памяти, GPU-масштабирование,
  лента миниатюр, полноэкранный режим, слайд-шоу, контекстные меню файлового менеджера.
